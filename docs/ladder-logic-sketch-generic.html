梯形图草图版

这份文档是 plc-final-formal-spec.md 的配套施工图。

规则：

  1. 如果和正式版冲突，一律以正式版为准
  2. 这份文档只负责回答“梯形图怎么落”
  3. 真实执行以 X / Y 为准，M300 ~ M339 只做安卓镜像，M500+ 只做内部逻辑

约定：

  1. [ ] 常开触点
  2. [/] 常闭触点
  3. ( ) 线圈
  4. (S) 置位
  5. (R) 复位
  6. (MOV) 数据搬运
  7. (DEC) 递减

11. 现在最适合你怎么用

如果你准备开始写 PLC，我建议：

  1. 先看 plc-final-formal-spec.md
  2. 边写边对着这份草图落网络
  3. 先跑通：
    • 相位
    • 加热
    • 应急补水
  4. 跑通以后再回头补细节文档
