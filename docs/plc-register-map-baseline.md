## 4. 读取字寄存器

| 功能 | PLC 寄存器 | Modbus 地址 | 状态 |
| --- | --- | --- | --- |
| 温度传感器 0 | `D200` | `0x00C8` | 已确认 |
| 温度传感器 1 | `D201` | `0x00C9` | 已确认 |
| 液位状态 | `D210` | `0x00D2` | 已确认 |

液位状态说明：
1. `0` = 超低液位
2. `1` = 低液位
3. `3` = 中液位
4. `7` = 高液位
5. 其他值 = 异常

项目代码对应：

## 8. 当前代码里的边界

当前项目代码已经把真实映射放进了 `PlcRegisterMap`，但还保留了一块：
`prototypeDispatchRegisters`

这一块只是为了让早期演示用的 `Order -> PLC` 占位流程还能继续编译，不代表真实 PLC 地址，也不应该参与正式联调。

## 9. 仍待二次核对的点

1. 手动按钮组里，`X06 ~ X11` 每一项和 `0x0132` 之后的逐项映射关系，还需要你按原表逐行核一下。
2. 表格示例里有两处像笔误：
   - 一处是读取 `Y` 状态的示例地址说明前后不一致。
   - 一处是 `0x00D4` 被文字说明成了 `D214`，但按行定义它应是 `D212`。
3. 这份基线目前只覆盖“通讯地址层”，还没开始定义“业务动作层”。
