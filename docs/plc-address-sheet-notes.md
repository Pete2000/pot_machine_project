## 1. 工作表结构

当前表格包含 3 张工作表：

1. `Main详细信息`
2. `主控板读取PLC当前状态值`
3. `主控写入PLC控制值`

## 2. 通讯基础信息

从 `Main详细信息` 可以确认：

1. 安卓主控板与 PLC 采用 `RS485`
2. 协议为 `Modbus RTU`
3. 波特率 `19200`
4. 数据位 `8`
5. 校验位 `无`
6. 停止位 `1`
7. PLC 从站地址 `1`

也就是当前默认配置可理解为：

`19200 / 8N1 / slaveId=1 / Modbus RTU / RS485`

## 3. 读取 PLC 当前状态

### 3.1 读取页字段

`主控板读取PLC当前状态值` 的主要列含义是：

1. 设备标识符
2. 功能文本
3. 数据类型
4. PLC 地址
5. 方向
6. 对应中转地址
7. 继电器或寄存器地址

### 3.2 DI 输入状态

表里已经定义了主控板需要读取的输入点，典型包括：

1. `X00` 按钮_控制急停
2. `X01` 按钮_控制加水
3. `X02` 按钮_传锅完成
4. `X03` 按钮_应急加水
5. `X04` 按钮_应急骨膏
6. `X05` 按钮_应急鸡油
7. `X06~X11` 出水阀相关按钮

这些点在中转区映射到：

`M300 ~ M319`

对应线圈地址大致从：

`0x012C ~ 0x013F`

### 3.3 DO 输出状态回读

表里也列了 PLC 输出点状态，典型包括：

1. `Y00` 主加热器
2. `Y01` 备加热器
3. `Y02~Y05` 出水气动阀 0~3
4. `Y06` 进水气动阀
5. `Y07` 单独出水阀
6. `Y10` 出水喷雾阀
7. `Y11` 鸡油输出泵
8. `Y12` 骨膏输出泵

这些点在中转区映射到：

`M320 ~ M339`

对应线圈地址大致从：

`0x0140 ~ 0x0153`

### 3.4 Word 寄存器读取

当前至少能确认这几个寄存器：

1. `D200` 温度传感器0 -> `0x00C8`
2. `D201` 温度传感器1 -> `0x00C9`
3. `D210` 液位状态 -> `0x00D2`

液位状态说明表里写得很明确：

1. `D210 = 0` 超低液位，加热器不能开启
2. `D210 = 1` 低液位
3. `D210 = 3` 中液位
4. `D210 = 7` 高液位
5. 其他值表示液位异常

## 4. 主控写入 PLC 控制值

### 4.1 线圈写入区

`主控写入PLC控制值` 里定义了主控板需要主动写给 PLC 的控制线圈。

核心是：

1. `M100 ~ M119`
2. 对应寄存器地址 `0x64 ~ 0x77`
3. 对应控制对象基本就是 `Y00 ~ Y23`

典型功能包括：

1. 主加热器
2. 备加热器
3. 出水气动阀 0~3
4. 进水气动阀
5. 单独出水阀
6. 出水喷雾阀
7. 鸡油输出泵
8. 骨膏输出泵

### 4.2 心跳脉冲

这里有一项非常关键：

1. `M400`
2. 地址 `0x190`
3. 安卓主板需要轮询式写入
4. 第一秒写 `1`
5. 下一秒写 `0`
6. 如此往复

表中说明，这个心跳脉冲用于：

1. 保证通讯断开后
2. PLC 对操作寄存器与继电器进行初始化

这意味着安卓端正式实现时，必须做一个稳定的心跳线程或定时任务。

### 4.3 Word 写入区

当前能明确看到两项应急参数写入：

1. `D212` 应急鸡油加量时间 -> `0x00D4`
2. `D214` 应急骨膏加量时间 -> `0x00D6`

## 5. Modbus 指令示例

表里直接给了几类报文示例：

1. 读保持寄存器 `03`
2. 读线圈状态 `01`
3. 写单个线圈 `05`
4. 写多个线圈 `0F`
5. 写单个保持寄存器 `06`
6. 写多个保持寄存器 `10`

这对安卓端非常有帮助，因为你后面写 Modbus RTU 时可以直接用这里的例子对照调试。

## 6. 对当前项目最有价值的结论

如果只提炼对安卓主控最关键的内容，目前最重要的是：

1. 串口参数已经明确
2. 从站地址已经明确
3. 出水阀、鸡油泵、骨膏泵的写入区已经明确
4. 温度、液位、输入按钮、输出状态的读取区已经明确
5. 心跳脉冲机制已经明确
6. 应急鸡油/骨膏时间写入区已经明确

## 7. 当前发现的疑点

这张表很有价值，但有几处建议你再核一下：

1. 读取 `Y` 状态示例里，请求报文是 `01 01 01 40 00 10 ...`
   但旁边拆解说明里有一处写成了 `01 2C`
   这看起来像表格文字笔误
2. 写单个保持寄存器示例中，说明文字写的是
   `写入0X00D4即PLC中D214的值`
   但表格行里
   `D212 -> 0x00D4`
   `D214 -> 0x00D6`
   这里大概率也有一处文字笔误

## 8. 对你当前学习最推荐的关注点

如果你是拿这个项目练习，我建议你先盯住下面这几个点理解：

1. 为什么读取区和写入区要分开
2. 为什么按钮状态、输出状态、模拟量寄存器要分不同功能码处理
3. 为什么心跳脉冲在工业通讯里很重要
4. 为什么地址表里既有 PLC 地址，又有中转地址/Modbus 地址
5. 安卓端应该怎样把“业务动作”映射成线圈和寄存器写入
