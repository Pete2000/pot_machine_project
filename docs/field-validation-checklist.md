# 现场验证清单

更新日期：`2026-06-18`

本文档用于区分三件事：

1. 代码能编译。
2. 单元测试能保护业务规则。
3. 真实 PLC 与现场流程确实跑通。

只有第 3 项通过，才算现场链路真正稳定。

## 0. 验证前准备

环境确认：

- 安卓屏已安装最新 APK。
- PLC 与上位机串口连接正常。
- 设置页串口参数正确：端口、波特率、数据位、停止位、校验位、帧间隔。
- Logcat 能筛选 `SerialModbus`、`PlcPolling`、`MachineCoordinator`。
- PLC 中能观察 M400 心跳。
- 急停、液位、主/备加热、备用泵硬件状态明确。

基础通过标准：

- `:app:testDebugUnitTest` 通过。
- `:app:assembleDebug` 通过。
- 首页 PLC 状态能从断线/异常恢复到正常。
- 设置/维护页能显示温度、液位、心跳、主要寄存器状态。

## 1. Modbus 与 PLC 状态验证

只读验证：

- 读取 D200/D201，温度显示为寄存器值除以 10。
- 读取 D210，液位按 0/1/3/7 和异常值规则显示。
- 读取 D320~D329，相位状态显示正常。
- 读取 D350~D359，加热状态显示正常。
- 读取 D370~D379，应急/单独加水状态显示正常。
- 读取 M300~M339，I/O 状态显示正常。

心跳验证：

- M400 按配置周期稳定翻转。
- 空闲、手动加水、订单加水和等待相位完成期间，M400 的翻转周期应保持一致，不出现额外短脉冲。
- 模拟一次 05 心跳写入失败后，下一次成功写入仍应与 PLC 实际状态连续，不因上位机缓存提前翻转而跳变。
- 上位机断开后，PLC 能按约定识别通信异常。
- 重新连接后，上位机能恢复正常轮询。

异常验证：

- 拔掉通讯线，UI 应在预期时间内提示通讯异常。
- 恢复通讯线，UI 应能回到 PLC 正常。
- Logcat 中要能区分读取失败、写命令失败、等待相位超时。

## 2. 手动模式加水验证

基础锅型：

- 单锅。
- 拼锅。
- 三拼锅。
- 四宫格。

普通锅底：

- 选择锅型和锅底后点击加水。
- 普通锅底按配方水量执行。
- 执行完成后手动锅底详情清空或进入明确完成状态，避免重复执行误判。

单个鸡油/骨膏锅底：

- 加料锅底在左上：应直接执行水 + 鸡油/骨膏。
- 加料锅底不在左上：应弹窗提示转到左上。
- 点击“已转到左上，开始执行”后，弹窗关闭，加水按钮应避免重复点击。
- 执行完成后，不应自动恢复原始锅底顺序，应保持当前转锅后的顺序。

多个鸡油/骨膏锅底：

- 第一个加料锅底优先转到左上并执行。
- 普通锅底可在第一相位同步加水。
- 其他加料锅底不能在未到左上时加鸡油/骨膏。
- 后续相位需要继续弹窗确认转锅。
- 点击“暂不处理”后，应回到可重新开始状态，订单或手动任务不应消失。

## 3. 接单模式验证

订单解析：

- 锅底顺序必须按接口数组顺序显示。
- 不使用 `potSort`。
- 锅型与锅底数量完整时，锅底详情显示完整。
- 接口缺失时，应显示结构异常提示，不乱补锅底。
- 解析缺失时，应尝试保守重解析；失败后禁止下发 PLC。

锅底详情：

- 显示锅底名。
- 口味大号高亮显示。
- 备注用括号显示。
- 显示底料信息和鲜辅料。
- 不显示加水秒数、鸡油秒数、骨膏秒数、物理出水口、来源、相位号。

加水执行：

- 单个鸡油/骨膏锅底如果不在左上，应按规则转到左上后执行。
- 多个鸡油/骨膏锅底应拆多相位。
- 普通锅底可在第一相位同步加水。
- 暂不处理后，订单回到待加水，可再次点击加水重新开始。
- 相位完成后进入待传锅。

## 4. 订单生命周期验证

催单：

- 同桌台多个锅底时，催单应命中对应锅底，不串锅。
- 催单胶囊打开后，催单订单置顶。
- 转台后再催单，不应出现转台单和催单单重复显示。

退单：

- 退单订单进入已取消。
- 已取消中应显示“重新加水”入口。
- 重新加水后回到待加水。

转台：

- 304 转台后，`mainPosOrder` 能命中上一单的 `posOrder` 或已记录 alias。
- 转台后的订单不应重复插入。
- 转台后的催单、退单仍能命中同一业务订单。

延时：

- 点击订单队列订单，弹窗确认加入延时。
- 延时胶囊可打开。
- 延时订单可恢复到待加水。
- 恢复后队列顺序和状态正确。

## 5. 加热与安全验证

加热允许：

- 上位机启动且 PLC 通讯首次恢复正常后，应下发 D341=11。
- 保存加热参数时，先 D341=10，再补 D341=11。
- PLC 断线恢复后，如果上位机仍处于正常运行态，应补发 D341=11。

安全约束：

- 急停时，加热不能开启。
- 液位超低 D210=0 时，加热不能开启。
- 主加热与备加热不能同时开启。
- 进入加热执行器配置并切换主/备时，应先短暂关闭允许加热，保存安全切换后再恢复。
- 进入水箱设置温度不应关闭加热允许。

## 6. 单独加水与备用泵验证

单独加水：

- 支持点动模式。
- 支持时控模式。
- 时控时间按设置生效。

备用泵：

- 鸡油泵可切备用。
- 骨膏泵可切备用。
- 鸡油和骨膏不能同时占用同一个备用泵。
- 当鸡油/骨膏都不使用备用泵时，不应误开启备用泵。

## 8. 停止条件

遇到下面情况，应暂停继续操作并先定位原因：

- PLC 无响应或持续通讯异常。
- CRC 错误重新出现。
- 写命令失败但 UI 仍显示执行中。
- 急停/液位超低下仍出现加热允许。
- 鸡油/骨膏/备用泵出现非预期同时动作。
- 转锅弹窗暂不处理后订单消失。
- 同一订单被催单/转台后重复出现。
