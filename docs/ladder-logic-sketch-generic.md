## 3. 相位命令识别与锁存

### D301 相位命令类型

`D301` 只负责相位执行域，当前先按下面 3 类处理：

| `D301` | 含义 | PLC 侧动作 |
| --- | --- | --- |
| `1` | 执行相位 | 校验 `D302 ~ D310`，锁存到 `D500 ~ D509`，进入相位运行 |
| `20` | 停止当前相位 | 立即停止相位输出，清运行 tick，回写停止状态 |
| `30` | 复位 / 清相位状态 | 不启动任何泵阀，只清相位状态机和状态回写，回到空闲 |

注意：

1. `20` 是“停动作”，用于订单取消、人工停止、异常中止。
2. `30` 是“清状态”，用于下一条命令开始前、取消完成后、开机初始化后清旧状态。
3. 正在运行时不建议直接执行 `30`，应先用 `20` 停止，确认停止后再 `30` 清状态。
4. `20/30` 也要求 `D300` 使用新的命令号，方便安卓通过 `D320/D322/D328` 确认 PLC 已处理。

### NW10 新相位命令识别

```text
|----[ D301 == 1 ]----[ D300 <> D320 ]----[ D300 <> D321 ]----[ D300 <> D322 ]----( M506 )----|
```

### NW10A 停止当前相位命令识别

```text
|----[ D301 == 20 ]----[ D300 <> D320 ]----[ D300 <> D322 ]----------------------( M509 )----|
```

说明：

1. `M509` 表示“收到停止当前相位请求”。
2. 停止命令不需要校验 `D302 ~ D310`，也不锁存水/鸡油/骨膏参数。
3. 停止命令的目的只有一个：让当前相位输出尽快全部关闭，并把状态回写为停止。

### NW10B 复位 / 清状态命令识别

这里使用 `M522` 作为相位复位请求内部位。

```text
|----[ D301 == 30 ]----[ D300 <> D320 ]----[ D300 <> D322 ]----------------------( M522 )----|
```

说明：

1. `M522` 只做相位状态清理，不启动任何输出。
2. 建议只在 `M502 phase_running` 不成立时执行复位。
3. 如果相位还在运行，应先发 `D301 = 20` 停止当前相位，再发 `D301 = 30` 清状态。

### NW23 收到停止命令 -> Stopped

停止命令 `D301 = 20` 的目标是“立刻停动作、保留停止结果”，不是清状态。

```text
|----[ M509 ]-----------------------------------------------(R) M501 ----|
|----[ M509 ]-----------------------------------------------(R) M502 ----|
|----[ M509 ]-----------------------------------------------(S) M505 ----|

|----[ M509 ]-----------------------------------------------(MOV K0 -> D510)----|
|----[ M509 ]-----------------------------------------------(MOV K0 -> D511)----|
|----[ M509 ]-----------------------------------------------(MOV K0 -> D512)----|
|----[ M509 ]-----------------------------------------------(MOV K0 -> D513)----|
|----[ M509 ]-----------------------------------------------(MOV K0 -> D514)----|
|----[ M509 ]-----------------------------------------------(MOV K0 -> D515)----|
|----[ M509 ]-----------------------------------------------(MOV K0 -> D326)----|

|----[ M509 ]-----------------------------------------------(MOV D300 -> D320)----|
|----[ M509 ]-----------------------------------------------(MOV D300 -> D322)----|
|----[ M509 ]-----------------------------------------------(MOV K5 -> D323)------|
|----[ M509 ]-----------------------------------------------(MOV K20 -> D324)-----|
|----[ M509 ]-----------------------------------------------(MOV K0 -> D325)------|
|----[ M509 ]-----------------------------------------------(MOV K20 -> D328)-----|
|----[ M509 ]-----------------------------------------------(MOV K0 -> D329)------|
```

说明：

1. 这里不建议在多个网络里直接重复驱动 `Y02 ~ Y05/Y11/Y12/Y13`。
2. 停止时通过复位 `M502` 并清 `D510 ~ D515`，让第 6 章的输出网络自然关闭所有相位输出。
3. `D323 = 5` 表示 `Stopped`。
4. `D324 = 20` 表示本次结果为停止完成。
5. `D328 = 20` 回显本次命令类型，安卓可据此确认 PLC 处理的是停止命令。

### NW24 收到复位命令 -> Idle

复位命令 `D301 = 30` 的目标是“清状态、准备下一条命令”，不是停止动作。

|----[ M522 ]----[/ M502 ]----------------------------------(R) M503 ----|
|----[ M522 ]----[/ M502 ]----------------------------------(R) M504 ----|
|----[ M522 ]----[/ M502 ]----------------------------------(R) M505 ----|
|----[ M522 ]----[/ M502 ]----------------------------------(S) M500 ----|

|----[ M522 ]----[/ M502 ]----------------------------------(MOV K0 -> D510)----|
|----[ M522 ]----[/ M502 ]----------------------------------(MOV K0 -> D511)----|
|----[ M522 ]----[/ M502 ]----------------------------------(MOV K0 -> D512)----|
|----[ M522 ]----[/ M502 ]----------------------------------(MOV K0 -> D513)----|
|----[ M522 ]----[/ M502 ]----------------------------------(MOV K0 -> D514)----|
|----[ M522 ]----[/ M502 ]----------------------------------(MOV K0 -> D515)----|
|----[ M522 ]----[/ M502 ]----------------------------------(MOV K0 -> D516)----|

|----[ M522 ]----[/ M502 ]----------------------------------(MOV D300 -> D320)----|
|----[ M522 ]----[/ M502 ]----------------------------------(MOV K0 -> D321)------|
|----[ M522 ]----[/ M502 ]----------------------------------(MOV D300 -> D322)----|
|----[ M522 ]----[/ M502 ]----------------------------------(MOV K0 -> D323)------|
|----[ M522 ]----[/ M502 ]----------------------------------(MOV K0 -> D324)------|
|----[ M522 ]----[/ M502 ]----------------------------------(MOV K0 -> D325)------|
|----[ M522 ]----[/ M502 ]----------------------------------(MOV K0 -> D326)------|
|----[ M522 ]----[/ M502 ]----------------------------------(MOV K0 -> D327)------|
|----[ M522 ]----[/ M502 ]----------------------------------(MOV K30 -> D328)-----|

说明：

1. `[/ M502]` 是关键条件：运行中不直接清状态。
2. `D323 = 0` 表示回到 `Idle`。
3. `D322 = D300` 表示复位命令已完成。
4. `D328 = 30` 回显本次命令类型，安卓可据此确认 PLC 处理的是复位命令。
5. 如果现场确实需要“运行中强制复位”，也应先在上位机发 `20`，等停止完成后再发 `30`，不要让 `30` 同时承担停止职责。
